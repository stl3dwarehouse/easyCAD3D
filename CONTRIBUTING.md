# Contributing feedback to easyCAD3D

Thank you for helping improve easyCAD3D. You do not need to write code to contribute.

## Choose where to post

- **[Bug report](https://github.com/stl3dwarehouse/easyCAD3D/issues/new?template=01-bug-report.yml):** an existing feature produces an error or does not behave as expected.
- **[Ideas and Suggestions](https://github.com/stl3dwarehouse/easyCAD3D/discussions/categories/ideas-and-suggestions):** discuss a new capability or an improvement to an existing workflow.
- **[Questions and Help](https://github.com/stl3dwarehouse/easyCAD3D/discussions/categories/questions-and-help):** get help finding or using a feature. Mark the answer when your question is solved.
- **[Show and tell](https://github.com/stl3dwarehouse/easyCAD3D/discussions/categories/show-and-tell):** share designs, prints, and helpful workflows.

The existing detailed suggestion and help forms are also available under [New issue](https://github.com/stl3dwarehouse/easyCAD3D/issues/new/choose). You do not need to post the same topic in both places.

## Make a bug reproducible

Include the version shown in easyCAD3D, the tool or mode, and a short numbered sequence of actions. Describe the expected result and what actually happened. If the problem involves Lithophane Maker or another installed library, include its version too.

Screenshots, exact error text, and a small sample project are helpful. Use a ZIP for project files, and remove private or licensed artwork that you cannot share publicly. Do not post passwords, activation keys, or payment details.

## Make suggestions concrete

Describe the task you are trying to complete, what slows you down, and the change that would help. A short example is more useful than a long list of unrelated features. Post separate suggestions for separate topics.

## Continue an existing conversation

Search Discussions and both open and closed issues before posting. Add a 👍 reaction to support an existing suggestion. Comment when you have new details, a reproducible example, or a useful workaround.

## How feedback is handled

Maintainers review reports, may ask for more information, and can link duplicate reports. Confirmed problems and accepted suggestions can be tracked in the same conversation. When a fix is released, maintainers can identify the version that includes it.

Submitting a suggestion does not guarantee implementation or a release date. Closed items should include an explanation, such as fixed, answered, duplicate, or not planned.

Keep conversations respectful and focused on the software. For account, billing, or activation support, use the contact options at [STL 3D Warehouse](https://www.stl3dwarehouse.com).
